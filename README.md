# Кофейня «12 грамм»

Сайт вымышленной кофейни с обжаркой: меню, магазин зерна с самовывозом и подбор кофе. Демо-проект для портфолио.

**Сайт:** https://danekkuznec.github.io/coffee-test12g/

## Что умеет

- **Магазин зерна.** Каталог из данных: выбор веса (250 г / 1 кг) и помола под способ заваривания, цена пересчитывается сразу.
- **Корзина** в боковой панели: количество, удаление, итоговая сумма. Сохраняется в браузере посетителя, а если хранилище недоступно — работает в памяти.
- **Оформление самовывоза:** день (сегодня, завтра, послезавтра) и время по часам работы с запасом на сборку заказа; проверка полей, маска телефона, номер заказа.
- **Подбор кофе за три вопроса:** способ заваривания, молоко, вкус → зерно по очкам и подходящий помол, добавление в корзину одной кнопкой.
- **Дата обжарки считается сама:** обжарка по понедельникам, в продаже — партия, которая уже отдохнула 3 дня.
- **Статус «Открыто / закрыто»** по московскому времени, независимо от часового пояса посетителя.
- **Первый экран:** падающие зёрна на `<canvas>` с параллаксом и плавный переход в светлую часть страницы. Анимация останавливается, когда экран не виден, и выключается при «уменьшении движения» в системе.
- Шапка меняет цвет над тёмным и светлым фоном, светлая и тёмная тема, адаптивная вёрстка, доступность с клавиатуры и для программ чтения с экрана.

Без фреймворков: разметка в `index.html`, стили в `css/style.css`, логика в `js/main.js`.

Заказы никуда не отправляются: это демо, кофейня вымышленная.
